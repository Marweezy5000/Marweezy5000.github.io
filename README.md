# My personal site

A simple, bilingual (English/Español) personal site. No frameworks, just three files you can open and read.

## What each file does

| File | Job |
|---|---|
| `index.html` | The content and structure: every heading, paragraph and link. |
| `styles.css` | The look: colors, fonts, spacing and layout. |
| `script.js` | The one interactive piece: the English/Español switch. |

## Common edits

- **Change the colors:** edit the hex values at the top of `styles.css` under "Color palette".
- **Change the fonts:** swap the Google Fonts link in `index.html` and the `--font-display` / `--font-body` lines in `styles.css`.
- **Edit text:** every sentence in `index.html` has an English version (`lang="en"`) and a Spanish version (`lang="es"`) next to each other. Update both.
- **Fill in placeholders:** search `index.html` for `class="todo"`. Those show with a dashed yellow outline until they're filled in.

## Publishing

The site is hosted for free with GitHub Pages from this repository. Any change pushed to the `main` branch goes live within a minute or two.
