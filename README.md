# My personal site

A simple personal site. No frameworks, just a few files you can open and read.

## What each file does

| File | Job |
|---|---|
| `index.html` | The content and structure: every heading, paragraph and link. |
| `styles.css` | The look: colors, fonts, spacing and layout. |
| `script.js` | The one interactive piece: the pixel portrait's hop. |
| `avatar.png` | The 32×32 pixel portrait. |

## Common edits

- **Change the colors:** edit the hex values at the top of `styles.css` under "Color palette".
- **Change the fonts:** swap the Google Fonts link in `index.html` and the `--font-display` / `--font-body` lines in `styles.css`.
- **Edit text:** all the words are in `index.html`.

## Publishing

The site is hosted for free with GitHub Pages from this repository. Any change pushed to the `main` branch goes live within a minute or two.
